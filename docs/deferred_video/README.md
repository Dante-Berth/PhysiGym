# Deferred Video Compilation — working notes

These documents describe the *deferred video compilation* feature added to PhysiGym
(rendering simulation frames during rollouts and compiling them into videos afterward,
rather than compiling inline).

They were previously kept in the repository root. They are working notes / a design
record for one feature and are not required to build or run PhysiGym.
